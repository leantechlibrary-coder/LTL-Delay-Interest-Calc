# 遅延損害金計算機（LTL Delay Interest Calc）

判決・和解後の振込額計算に特化した遅延損害金計算ツールです。
裁判所方式（端数期間暦年閏年説）と年365日日割特約に対応しています。

- **デスクトップ版**（Windows 10 / 11）: Microsoft Store で配布。`main.py` + `calc_engine.py`
- **Web版（PWA）**: `site/` 以下の静的ファイル。ブラウザだけで動作

どちらも完全オフラインで動作し、入力内容の送信・保存は行いません（[PRIVACY.md](PRIVACY.md)）。

## 計算方法

| 方式 | 式 |
|---|---|
| 特約なし（既定） | 元本 × 年利 ×（年数 ＋ 平年日数÷365 ＋ 閏年日数÷366） |
| 年365日日割特約 | 元本 × 年利 × 総日数÷365 |

- **起算日**: 判決の「○日から支払済みまで」の日をそのまま入力します（初日は「算入」が既定）。
  起算日の翌日から数える場合は「不算入」を選びます。
- **年に満つる期間**: 応当日の前日に満了します（民法143条2項）。
  例: 7/1 起算なら翌年 6/30 で満1年、7/1 からが端数期間。
  2/29 起算で応当日がない年は 2/28 に満了します（同項ただし書）。
- **端数期間**: 暦年ごとに区切り、閏年に属する日は ÷366、平年に属する日は ÷365。
- **端数処理**: 「各区間ごとに切り捨て」（既定）または
  「合算後に切り捨て」（東京地裁執行部方式: 各区間を小数第2位で切り捨て → 合算 → 円未満切り捨て）。
- 金額は整数演算で厳密に切り捨てます（浮動小数点の誤差を持ち込みません）。

入力できる範囲: 元本 999,999,999,999円まで、年利 100%まで（小数第4位まで）、
日付は和暦（昭和・平成・令和）または西暦。

## ファイル構成

```
main.py            デスクトップ版の画面（PyQt6）
calc_engine.py     計算エンジン（Python）
requirements.txt   デスクトップ版の依存ライブラリ
site/              Web版一式（calc.js は calc_engine.py と同じ結果・同じ明細文を返す）
tests/             計算エンジンの検証スクリプト
BUILD.md           デスクトップ版のビルド・Store 提出手順
site/DEPLOY.md     Web版のデプロイ手順
```

## 開発

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

計算ロジックを変更したら、`calc_engine.py` と `site/calc.js` の両方を同じ内容に直し、検証を実行します
（Python のみで動作。node があれば calc.js との照合も行います）。

```bash
python tests/check_engines.py
```
